# andre123-afk-ecomarket_andres_rueda
## Descripcion del proyecto:
EcoMarket es una página web desarrollada para la venta de productos ecológicos y sostenibles. Su objetivo es promover el cuidado del medio ambiente mediante la comercialización de artículos reutilizables como botellas ecológicas, bolsas reutilizables y kits sostenibles. La plataforma permite a los usuarios explorar productos, conocer información de la empresa y comunicarse fácilmente a través de la sección de contacto.
## Instrucciones de visualización
1. Clonar el repositorio del proyecto.
2. Abrir la carpeta EcoMarket.
3. Abrir el archivo index.html en un navegador web.
4. Navegar por las diferentes secciones de la página.
